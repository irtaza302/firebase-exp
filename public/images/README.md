# Image Assets for BootRocket Website

This directory contains all the image assets needed for the website.

## Directory Structure

- `/courses`: Course thumbnail/cover images
- `/instructors`: Instructor profile photos
- `/testimonials`: User testimonial profile photos
- `/logos`: Partner/company logos used in testimonials and other sections

## Image Requirements

### Course Images

- Recommended size: 800x600px
- Format: JPG or WebP
- Use descriptive filenames like `photoshop-advanced.jpg`

### Instructor Images

- Recommended size: 400x400px
- Format: JPG, PNG, or WebP
- Use descriptive filenames like `daniel-scott.jpg`

### Testimonial Images

- Recommended size: 200x200px
- Format: JPG, PNG, or WebP

### Logo Images

- Recommended size: maximum height of 60px
- Format: SVG preferred, PNG with transparency also acceptable

## Placeholder Images

For development, you can use placeholder image services like:

- https://placeholder.com/
- https://picsum.photos/

Example placeholder: `https://picsum.photos/800/600`

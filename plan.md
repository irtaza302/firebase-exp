# BootRocket Website Clone - Development Plan

## Project Overview

Creating a frontend clone of the [BootRocket](https://bringyourownlaptop.com/) website using Next.js with TypeScript, Tailwind CSS, and modern web development practices.

## Tech Stack

- **Framework**: Next.js 15.3.0
- **Language**: TypeScript with strict mode
- **Styling**: Tailwind CSS
- **Components**: Server components by default, client components where needed
- **Font**: Geist (already configured)

## Project Structure

- `app/`: Pages and layouts
- `components/`: Reusable UI components
  - `layout/`: Layout components (header, footer, etc.)
  - `ui/`: Reusable UI elements (buttons, cards, etc.)
  - `courses/`: Course-related components
  - `home/`: Homepage-specific components
- `lib/`: Utilities and helpers
- `public/`: Static assets
